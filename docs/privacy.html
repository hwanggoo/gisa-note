기사의 노트 개인정보처리방침

시행일: 2026년 11월 19일

「기사의 노트」(이하 "앱")는 현장 기사가 고장 기록을 남기는 메모 앱입니다. 앱은 사용자의 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.

1. 수집하는 정보

앱은 회원가입, 로그인, 광고, 분석 도구를 사용하지 않으며 개발자가 사용자 정보를 수집하지 않습니다.

2. 기기 안에 저장되는 정보

사용자가 입력한 메모, 장비·증상·원인·조치 내용, 현장 정보, 사진은 사용자의 기기 안에만 저장됩니다. 앱을 삭제하면 함께 삭제됩니다. 사용자가 직접 "백업 내보내기"를 실행한 경우에만 사용자가 고른 곳(메신저, 클라우드 등)으로 파일이 공유됩니다.

3. 사용하는 권한

  • 카메라·사진: 현장 사진을 찍거나 앨범에서 고를 때 사용하며, 사진은 기기 안에만 저장됩니다.

4. 제3자 제공

앱은 사용자 정보를 제3자에게 제공하지 않습니다.
